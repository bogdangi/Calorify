📝 User Story: Export / Import Backup

Title: Local Backup via Export/Import
Feature: JSON export and validated JSON import in Settings (the only backup mechanism)
User Story:
• As a user whose data lives only on this device,
• I want to export all my data as JSON and import a validated backup,
• So that I can recover from device loss or app changes without any server.

Status: ✅ Done — `SettingsPage.tsx` (download/upload, confirm dialog), `utils/validation.ts` (`validateExportJson`), `types/export.ts`.

⚙️ Acceptance Criteria

1. Export format:
{
  "version": 1,
  "exportedAt": "...",
  "meals": [],
  "weights": [],
  "settings": {}
}

2. Import: validate JSON and schema, reject malformed data, do not accidentally overwrite existing data, clear success/error messages, preserve IDs and timestamps where appropriate.
