📝 User Story: Over-Engineering Cleanup (Leanness Pass)

Title: Over-Engineering Cleanup
Feature: Cut ~280 lines of dead code, reinvented stdlib and unused abstractions identified by the 2026-10-25 whole-tree audit (findings only — none applied yet)
User Story:
• As a maintainer,
• I want the codebase stripped of write-only abstractions, dead exports and reinvented platform features,
• So that the model-swap work (US-9) lands in the smallest possible surface.

Status: 🔜 Todo — sourced from whole-repo ponytail-audit; ranked biggest cut first. Behavior must not change (tests stay green).

⚙️ Acceptance Criteria

1. Biggest cut — inline styles → CSS
• ~82 JSX `style={{...}}` objects (PhotoCaptureModal 38, SettingsPage 27, MealFormModal 7, WeightFormModal 5, App install banner 5) move to existing `styles/index.css` classes.

2. Platform reinventions → native
• `src/test/setup.ts`: delete the 40-line `LocalStorageMock` and `matchMedia` stub — jsdom v29 provides both; keep only `fake-indexeddb/auto` + jest-dom imports.

3. Repository layer slimming
• Repository constructor DI exists but is never injected (always default `db`) — remove the param or collapse classes.
• Pure delegate methods (`getAll→toArray`, `bulkAdd→bulkPut`, `delete→delete`) removed; keep only the timestamp-stamping `create`/`update` helpers.
• Resolve the hooks-vs-repositories duplicate data paths (hooks query Dexie tables directly): keep one canonical path (hooks, via liveQuery), delete repo `getByDate`/`getByDateRange` or re-point.

4. Dead code deleted
• `defaultVisionPipeline` singleton (src/ml/pipeline/visionPipeline.ts) — hooks always construct their own.
• `getNowIsoString` (src/utils/date.ts).
• `mealRepository.getById`; unused `clear()` in all three repositories.
• `modelRegistry.register()` / whole `ModelRegistry` Map class → `AVAILABLE_MODELS.find(m => m.id === id)`.
• `VisionStatus` state `'model_ready'` — never assigned by any `setStatus`.
• `formatConfidence`'s unused `_language` parameter.

5. Shape shrinks
• `PortionEstimate.method` union of 3 values with a single producer → literal value or dropped field.
• `MockPortionEstimator`: remove the `Math.sin(foodId.length)` fake variance; return `defaultServingGrams` directly.
• `LocalNutritionProvider`: drop never-passed constructor DI and the unused pre-computed `calculatedCalories` field; a plain array + `find` is sufficient.
• Hook `addMeal/updateMeal/deleteMeal/deleteWeight/...` wrappers that only forward to repositories → return the repository methods (or call them directly).
• `useVisionPipeline`: drop `setLanguage()` (pipeline already rebuilds via `useMemo` on language).

6. Guardrails
• `npm test`, `npm run build`, `npm run lint` stay green after each cut.
• Explicitly NOT cut (protected): ML interfaces + mocks (ADR-0004/ADR-0010), hand-rolled SVG charts (spec: lightweight charts, no new dep), ONNX→heuristic fallback (needed until US-9 ships the model file).
