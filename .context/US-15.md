📝 User Story: Settings

Title: Settings
Feature: Single settings page (language, calorie goal, backup, model/privacy info, version)
User Story:
• As an app user,
• I want one place to set my calorie goal and language, manage backups, and see model/privacy/version info,
• So that I can configure the app without technical maintenance burden.

Status: ✅ Done — `SettingsPage.tsx` (interestingly covers language/export/import; cross-references US-13/US-14 rather than duplicating criteria).

⚙️ Acceptance Criteria

1. Includes: language (→ US-14), daily calorie goal, export data & import data (→ US-13), ML/model information, privacy information, app version.
2. No complex medical recommendations are provided.
