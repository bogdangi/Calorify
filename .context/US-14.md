📝 User Story: Internationalization (German & Ukrainian)

Title: Internationalization de/uk
Feature: Full de/uk translation with persisted preference and locale-aware formatting
User Story:
• As a German- or Ukrainian-speaking user,
• I want the whole app in my language with instant switching,
• So that I can use the app natively.

Status: ✅ Done — `src/i18n/` (`index.ts`, `locales/de.ts`, `locales/uk.ts`), fallback `de`.

⚙️ Acceptance Criteria

1. Languages: German (de) and Ukrainian (uk); default German.
2. First-launch resolution: saved preference → browser language → German fallback.
3. Language selection in Settings; switching happens immediately and persists locally.
4. No hardcoded user-facing text in React components; translations cover navigation, buttons, forms, errors, validation, empty states, statistics, charts, dialogs, settings, ML messages, camera UI, import/export, accessibility labels, PWA instructions.
5. `Intl.DateTimeFormat` / `Intl.NumberFormat` for locale-aware formatting; internally kg/g/ml/kcal, localized presentation only.
6. Meal types remain language-independent enums (breakfast/lunch/dinner/snack); i18n structure `src/i18n/{index.ts, locales/{de.ts, uk.ts}}`.
