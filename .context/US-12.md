📝 User Story: PWA with Offline Support

Title: PWA & Offline
Feature: Installable offline-first app (manifest, service worker, cached assets)
User Story:
• As a mobile user,
• I want to install the app and use all its features offline,
• So that tracking works anywhere without a network connection.

Status: ✅ Done — `vite-plugin-pwa` v2 in `vite.config.ts` (manifest, `autoUpdate`, workbox caching, icons incl. `models/*` precache allowance up to 35 MB).

⚙️ Acceptance Criteria

1. Web App Manifest, service worker, installability, offline caching, app icons, offline application shell, cached assets.
2. Offline core: add/edit/delete meals, add/edit/delete weight, statistics, settings.
3. ML models may require an initial download; cache models locally after download when practical.
4. Error handling covers offline state gracefully (see US-16).
