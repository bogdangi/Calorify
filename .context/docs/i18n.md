# Internationalization (de/uk)

Source: TODO.md §19

- Languages: German (`de`, default/fallback), Ukrainian (`uk`).
- First launch: saved preference → browser language → German fallback.
- Language selection in Settings; switching is immediate and persisted locally.
- Structure: `src/i18n/{index.ts, locales/{de.ts, uk.ts}}`.
- Never hard-code user-facing text inside React components.

Translate: navigation · buttons · forms · errors · validation · empty states · statistics · charts · dialogs · settings · ML messages · camera UI · import/export · accessibility labels · PWA instructions.

Formatting: `Intl.DateTimeFormat` / `Intl.NumberFormat`. Internal units kg/g/ml/kcal, localized presentation only. Meal types stay language-independent (breakfast/lunch/dinner/snack).
